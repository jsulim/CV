# CV

GitHub Pages로 배포할 개인 CV 사이트입니다.

## 수정 방법

- `index.html`에서 이름, 연락처, 경력, 프로젝트, 학력을 수정합니다.
- `styles.css`에서 색상과 레이아웃을 수정합니다.

## GitHub Pages URL

이 저장소가 `jsulim/CV`라면 Pages URL은 보통 아래 형식입니다.

```text
https://jsulim.github.io/CV/
```

GitHub 저장소의 `Settings > Pages`에서 `Deploy from a branch`, `main`, `/root`를 선택하면 배포됩니다.
